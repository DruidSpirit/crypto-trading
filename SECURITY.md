# Security Policy

## Supported versions

Security fixes are accepted for the current `main` branch and the latest
published release.

## Reporting a vulnerability

Please report security issues privately by opening a GitHub issue with a
minimal description and asking for a private follow-up channel, or by contacting
the repository owner directly through GitHub.

Avoid posting exploit details, secrets, API keys, or account-specific trading
data in public issues.

## Scope

Relevant issues include:

- Exposure of API keys, proxy credentials, or local database contents.
- Server-side request forgery or unsafe exchange API handling.
- Unsafe strategy upload, strategy execution, or file path handling.
- Authentication, authorization, or data leakage issues in future hosted
  deployments.

## Trading risk

Crypto Trading is research software for generating and testing trading signals.
It does not provide financial advice. Always validate strategies independently
before using them with real funds.
